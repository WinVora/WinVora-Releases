BUILT WITH TRANSPARENCY

You decide what WinVora does

Cleanup, updates, and uninstall actions only run after you select them. Administrator access is requested only when Windows requires it for that specific action.

  • SHA-256 checksum with every installer

  • Diagnostic reports can be reviewed before saving

About SmartScreen

WinVora is a solo open-source project and the installer is not yet code-signed with a paid certificate. Windows may therefore show an “Unknown publisher” message.

Only download WinVora from the official GitHub release page. The optional checksum lets you verify the installer independently.
