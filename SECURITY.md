# Security Policy

## Supported Versions

Security fixes are provided for the latest published version of WinVora.

| Version | Supported |
| --- | --- |
| 0.8.4 | Yes |
| Older versions | No |

Please update to the latest release before reporting a security problem.

## Reporting a Vulnerability

Please do **not** report security vulnerabilities through a public GitHub issue.

Send a private email to [winvoraadmin@gmail.com](mailto:winvoraadmin@gmail.com) with:

- the affected WinVora version;
- your Windows version;
- a clear description of the issue;
- steps to reproduce it, if possible;
- any relevant screenshots or log excerpts with personal information removed.

You will receive an initial response as soon as possible. Please allow time to investigate the report before sharing details publicly.

## Privacy

Remove usernames, serial numbers, local paths, IP addresses, and other personal information from screenshots and logs before sending them.
